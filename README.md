# DEK Sound

L'optimisation du son pour Warzone et Black Ops, par DEK DEV : les pas ennemis ressortent, votre tir, les explosions et
l'ambiance passent en retrait, chaque son reste à sa place autour de vous.

- **Télécharger** : la dernière version est dans [Releases](../../releases/latest) (`DEK-Sound.exe`, Windows 10 / 11, 64 bits).
- **Essai gratuit de 15 jours**, avec une clé d'essai à demander sur le Discord DEK DEV (salon Opti Son), puis licence à vie.
- Français, English, Español, Português.

Discord DEK DEV : https://discord.gg/ZNpy4FjChU
